# Model card Basic information sources

Reviewed: 2026-11-10. Public Jellytoken model marketplace: https://www.jellytoken.com/models.
The website uses getModelDetail(modelCode), displaying desc with remark as fallback.
Cards use condensed translations, not measured promises. Only exact model IDs match.
GPT variants and IDs absent from that public source use neutral, task-focused
suggestions so cards remain distinct without making measured capability claims.

The shipped GPT and light-model recommendations therefore have their own
task summaries: Astra is described as a flagship for advanced reasoning and
long-horizon agent work; Sol as a balanced writing and coding workhorse; Terra
and Luna as lightweight options for routine text tasks; and the Qwen, Doubao
and dated DeepSeek entries are keyed to their exact IDs rather than inheriting
one tier's generic fallback.
